# Features extendidas

Propósito: definir el papel de los descriptores fuera del core23.

## Por qué existe el conjunto extendido

Los descriptores extendidos se mantienen para:

- diagnóstico más rico,
- interpretación específica por familia,
- dashboard y análisis suplementarios.

No son la base metodológica principal para reporte final de diversidad.

## Motivos típicos de exclusión del core

- carácter derivado/redundante con descriptores más fuertes,
- cobertura baja o aplicabilidad muy condicional,
- detalle de implementación con impacto transversal débil.
