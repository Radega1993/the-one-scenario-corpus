# Feature selection rationale

Purpose: summarize how features were selected and classified.

## Selection criteria

- Structural relevance for scenario identity.
- Cross-family usefulness (corpus-wide behavior).
- Interpretability for review and reproducibility.
- Redundancy control inside the core set.

## Final decision pattern

- Keep core compact (`core23`) for methodological clarity.
- Keep extended (`full46`) for richer diagnostics and complementary analysis.
- Track residual dependencies explicitly (not hidden).
