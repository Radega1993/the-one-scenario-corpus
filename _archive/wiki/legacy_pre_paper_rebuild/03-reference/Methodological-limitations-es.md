# Limitaciones metodológicas

Propósito: declarar limitaciones residuales del baseline congelado.

## Limitaciones declaradas

1. Persisten algunos pares de escenarios altamente correlacionados, aunque reducidos de forma material.
2. `core23` no recupera su nivel previo de silhouette tras las rondas de optimización.
3. Se mantiene una dependencia residual alta entre `mm_WDM` y `mm_Bus` (`0.9393`).

## Posicionamiento

Estas limitaciones se documentan de forma explícita para sostener una metodología transparente y publicable.
