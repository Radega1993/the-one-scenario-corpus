# Scenario catalog

**English** | [Español](Scenario-catalog-es)

---

Index of all **60 scenarios** in corpus_v1. Each scenario is one `.settings` file.

Catalog organization is two-level:

1. Family index pages (`Urban`, `Campus`, ...).
2. Per-scenario sheets with a fixed structure (overview, objective, core configuration, mobility, traffic, distinguishing features, top-3 similarity, outputs if available).

For scenario-level documentation, see **[Scenario details](Scenario-details)**.

## Detailed description of each scenario

**[Scenario details](Scenario-details)** lists all 60 scenarios one by one with links to per-scenario pages. Each scenario page documents purpose, mobility, core features, traffic, expected behaviour, correlation, cluster assignment, and simulation outputs. The settings file path is given in the family index pages (e.g. [Campus scenarios](Campus-scenarios)).
