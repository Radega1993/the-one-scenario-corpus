# Core vs extended features

Propósito: explicar por qué se usan dos espacios descriptores.

## Espacios

- **core23**: referencia metodológica para interpretar diversidad y narrativa del paper.
- **full46**: espacio operativo para controlar redundancia y mantener cobertura descriptora.

## Interpretación en el freeze final

- `core23` es más interpretable y liviano para discusión metodológica.
- `full46` ofrece mejor control de redundancia en el snapshot final optimizado.
