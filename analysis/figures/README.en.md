# Figures catalog (corpus_v2)

Spanish is the **canonical** guide: [README.md](README.md).

**Quick reference**

- **Use for papers:** `paper/main/*`, `aggregated/outputs_*`, `message_creation_time_*`.
- **Avoid for reading:** 720×720 heatmaps (`heatmap_pearson`, etc.) — keep CSVs only unless `--include-full-heatmaps`.
- **Regenerate aggregated figures:** `python3 run_figures_aggregated.py --corpus corpus_v2`
